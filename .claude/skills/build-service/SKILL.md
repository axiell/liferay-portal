Regenerate Service Builder output for the named module.

## Steps

1. Find the *-service module directory:

```bash
find /opt/projects/liferay/portal/arena-7.4.3.129-ga129/portal/modules -maxdepth 6 -type d -name "$MODULE" 2>/dev/null | head -3
```

2. Run buildService from that directory:

```bash
cd <module-dir>
../../../../gradlew buildService
```

3. Show a stat of changed generated files:

```bash
git -C /opt/projects/liferay/portal/arena-7.4.3.129-ga129/portal diff --stat -- <module-dir>
```

Flag any file that appears in the diff but was NOT generated (i.e. a hand-written *Impl file) — those are safe. Flag any file under `service/base/` or with `@autogenerated` that shows unexpected local changes — those indicate a prior hand-edit that will be lost on the next buildService.
